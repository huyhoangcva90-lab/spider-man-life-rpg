# Spidey Tracker reference assets

Imported on 2026-08-22 from `https://spideytracker.net/` for the user's local Life Spider-Man prototype.

The folder preserves the original tracker logo, map pins, filter buttons, radar, controls, and Spider-Man sprite strips requested by the user. `combat-actions-sheet.png` is the combat reference sheet supplied directly by the user. `spider-allies-sheet.png` is the user-supplied 10×10 Spider-Verse ally roster used by the in-app ally selector.

These files remain third-party reference assets and are kept together here so their provenance is explicit. Review the original site's and character owner's rights before any public or commercial release.
